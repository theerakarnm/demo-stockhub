### Assumptions the plan makes where the brief is silent

1. **Scene 3 = 103,400 baht.** No demo script is in the repo (`grep -rn "103,400\|103400\|ฉาก"` over the repo and the sibling folders returns nothing). Task 8 encodes the customer-facing figure as a lot/sale scenario that yields exactly 103,400 baht (60 units at 1,000.00 from the older lot + 40 units at 1,085.00 from the newer lot, selling 100). The assertion on 103,400 is the requirement; the lot quantities and unit costs must be replaced with the demo script's numbers before execution if they differ.
2. **Price tier semantics.** Three seeded tiers (`retail` ปลีก = default, `wholesale` ส่ง, `dealer` ตัวแทน). Resolution order: the customer's tier price, else the default tier price, else the variant's `sellingPrice`; the API reports which one it used (`priceSource`) so the bill screen can say so.
3. **Who sees tier prices.** Permission `price_tier:read` is granted to owner, manager and sales (sales needs it to bill); `stock_staff` gets neither cost nor tier data. `price_tier:write` and `customer:write` go to owner, manager and sales; `customer:read` to owner, manager, sales.
4. **Receiving goods needs cost.** `POST /inventory/receive` requires `stock:adjust` to call and `cost:write` to set the unit cost; a role without `cost:write` gets 403, because an inbound layer with no cost breaks FIFO (`apps/api/src/services/inventory-service.ts:84`).
5. **Marketplace shortfall.** When a marketplace sale exceeds open lots (`onShortage: 'shortfall'`), the ledger records only the units that had a lot (`qtyDelta = -consumed`) and reports `shortfallQty`; this keeps the DB invariant `SUM(qty_delta) = SUM(remaining_qty)` that `packages/db/src/guards.integration.test.ts:121-130` asserts. Wave 1 exercises this path in core unit tests only; the import applier (Wave 2) surfaces the shortfall to the user.

## Global Constraints

Copied from `AGENTS.md` (iron rules and conventions) and the codebase; every task implicitly includes these.

- `packages/core` must not import Next.js, Hono, Drizzle, React, or the Cloudflare runtime; core must be testable with plain `bun test` (`AGENTS.md` rule 1).
- Adapters only convert data: no database, no HTTP, no stock decisions; an adapter must not throw on a bad row, it pushes a `ParseIssue` and continues (`AGENTS.md` rule 2).
- Money is always an integer in satang via the `Satang` type; never floats; convert to decimal only when displaying (`AGENTS.md` rule 3).
- Cost hiding is enforced at the API: every response goes through `ok()` / `paginated()` in `apps/api/src/lib/response.ts`; when adding a field that contains cost, add its key to `COST_KEYS` in `packages/core/src/rbac.ts` in the SAME commit (`AGENTS.md` rule 4).
- FIFO runs in a single transaction: `SELECT ... FOR UPDATE` on lots, compute with pure functions, write back, all inside one `db.transaction` (`AGENTS.md` rule 5).
- Re-importing a file must not deduct stock twice; the unique index `orders_channel_external_uq` is the lifeline (`AGENTS.md` rule 6).
- Returns restore the original cost: `restoreFifo` takes the `LotConsumption[]` of the original sale, never today's cost (`AGENTS.md` rule 7).
- Every business table carries `org_id`; every repository query filters by `orgId` (`packages/db/src/schema/_shared.ts:28-31`, e.g. `packages/db/src/repositories/inventory-repo.ts:57`).
- TypeScript strict with `noUncheckedIndexedAccess` and `verbatimModuleSyntax`: always `import type` for types, no `any`, no `!` non-null assertion (`AGENTS.md` section 4).
- Files `kebab-case.ts`; types `PascalCase`; functions and variables `camelCase`; constant arrays of a union `SCREAMING_SNAKE_CASE` declared next to their type; DB tables plural `snake_case`, Drizzle variables `camelCase`.
- Enums: edit `packages/core/src/domain/enums.ts` first, then `packages/db/src/schema/enums.ts`, then `bun run db:generate`; `ENUM_SYNC_GUARD` fails typecheck on drift.
- Throw only `StockHubError` or a subclass with a stable `code`; add new codes to `ERROR_STATUS` in `apps/api/src/middleware/error.ts:19-28`.
- Comments in English explaining why; on-screen text in Thai; Markdown one sentence per line; never the em dash character, use `-`.
- Commit subjects at most about 50 characters, imperative, one commit does one thing, never add an AI agent as co-author.
- Schema change means `bun run db:generate` and committing the SQL, the `meta/NNNN_snapshot.json` and the appended `meta/_journal.json`; never hand-edit SQL (`packages/db/README.md:35`).
- New endpoint: zod schema in `apps/api/src/schemas/`, handler returns only through `ok()` / `paginated()`, guarded with `requirePermission()`, matching types and functions on the web side, contract table in `apps/api/README.md` updated (`AGENTS.md` section 5).
- Contract marker rule (new in this plan, enforced by Task 38 and Task 40): every field in `apps/api/src/types/contract*.ts` whose name is in `COST_KEYS` carries the doc comment `/** cost field */` on the line above it, and every field whose name is in `PRICE_TIER_KEYS` (`priceTierId`, `priceTierCode`, `priceTierName`, `tierPrices`, `priceSource`) carries `/** tier field */`. The comment is how a reviewer sees that the field is stripped by role; the audit test fails on a marked key that is missing from the set, and Track P fails on a set key that is unmarked.
- Web pages fetch only through the API modules under `apps/web/src/lib/` (never `fetch` in a component), render loading, empty and error states, wrap every cost figure in `<CostValue>`, and put `role` in every `useApi` dependency list (`apps/web/README.md:83-99`). ### Data access - repository function shape and the FIFO lock
<!-- SOURCE: packages/db/src/repositories/inventory-repo.ts:48-73 -->
```ts
export const getOpenLotsForUpdate = async (
  exec: DbExecutor,
  query: LotQuery,
): Promise<DomainStockLot[]> => {
  const rows = await exec
    .select()
    .from(stockLots)
    .where(
      and(
        eq(stockLots.orgId, query.orgId),
        eq(stockLots.variantId, query.variantId),
        eq(stockLots.warehouseId, query.warehouseId),
        gt(stockLots.remainingQty, 0),
      ),
    )
    .orderBy(asc(stockLots.receivedAt), asc(stockLots.id))
    .for('update');

  // Map the DB row onto the domain shape the FIFO engine expects.
  return rows.map((row) => ({
    id: asStockLotId(row.id),
    variantId: asVariantId(row.variantId),
    remainingQty: row.remainingQty,
    unitCost: satang(row.unitCost),
    receivedAt: row.receivedAt,
  }));
};
```

### Idempotent upsert
<!-- SOURCE: packages/db/src/repositories/order-repo.ts:28-48 -->
```ts
export const upsertOrder = async (exec: DbExecutor, values: NewOrder): Promise<Order> => {
  const [row] = await exec
    .insert(orders)
    .values(values)
    .onConflictDoUpdate({
      target: [orders.channelId, orders.externalOrderId],
      set: {
        status: values.status ?? 'pending',
        shippedAt: values.shippedAt ?? null,
        cancelledAt: values.cancelledAt ?? null,
        buyerName: values.buyerName ?? null,
        grandTotal: values.grandTotal ?? 0,
        raw: values.raw ?? null,
        updatedAt: new Date(),
      },
    })
    .returning();

  if (!row) throw new Error('Upsert into orders returned no row');
  return row;
};
```

      ```ts
        lines: readonly { variantId: VariantId; qty: number }[],
        componentsByBundle: ReadonlyMap<VariantId, readonly BundleComponent[]>,

        const out: ExpandedLine[] = [];
        for (const line of lines) {

          if (components === undefined || components.length === 0) {
            out.push({ variantId: line.variantId, qty: line.qty });

          const existing = byKey.get(key);
      ```

      ```ts
      export const consumeFifo = (lots, qty, options): ConsumeResult => {
        if (!Number.isInteger(qty) || qty < 0) {
          throw new StockHubError('validation_error', 'Quantity must be a non-negative integer', { qty });
        }
        const consumed: LotConsumption[] = [];
        let needed = qty;
        let totalCost = 0;
        for (const lot of [...lots].sort(byFifoOrder)) {
          if (needed === 0) break;
          if (lot.remainingQty <= 0) continue;
          const take = Math.min(lot.remainingQty, needed);
          const lineCost = mulMoney(lot.unitCost, take);
          consumed.push({ lotId: lot.id, qty: take, unitCost: lot.unitCost, lineCost });
          totalCost += lineCost;
          needed -= take;
        }
        if (needed > 0 && options.onShortage === 'error') {
          const available = lots.reduce((sum, lot) => sum + Math.max(lot.remainingQty, 0), 0);
          throw new InsufficientStockError(lots[0]?.variantId ?? 'unknown', qty, available);
        }
        return { consumed, totalCost: satang(totalCost), shortfallQty: needed };
      };

      export const restoreFifo = (originalConsumption, qtyToRestore) => {
        const restored: LotConsumption[] = [];
        let remaining = qtyToRestore;
        let totalCost = 0;
        // Newest consumed slice first, so a second partial return keeps walking backwards.
        for (const slice of [...originalConsumption].reverse()) {
          if (remaining === 0) break;
          const give = Math.min(slice.qty, remaining);
          const lineCost = mulMoney(slice.unitCost, give);
          restored.push({ lotId: slice.lotId, qty: give, unitCost: slice.unitCost, lineCost });
          totalCost += lineCost;
          remaining -= give;
        }
        if (remaining > 0) {
          throw new StockHubError('validation_error', 'Cannot restore more units than the sale consumed', {
            qtyToRestore, consumed: qtyToRestore - remaining,
          });
        }
        return { restored, totalCost: satang(totalCost) };
      };

      export const valueOfLots = (lots) => satang(lots.reduce((sum, lot) => sum + mulMoney(lot.unitCost, lot.remainingQty), 0));

        const units = lots.reduce((sum, lot) => sum + lot.remainingQty, 0);
      ```

      ```ts
        const na = normaliseSku(a), nb = normaliseSku(b);
        if (na === nb) return 1;
        if (na.length >= 4 && nb.length >= 4 && (na.includes(nb) || nb.includes(na))) return 0.8;
        const ba = bigrams(na), bb = bigrams(nb);
        if (ba.size === 0 || bb.size === 0) return 0;
        let shared = 0; for (const g of ba) if (bb.has(g)) shared++;
        return (2 * shared) / (ba.size + bb.size);   // Dice coefficient
      };
      export const suggestCandidates = (platformSku, index, limit) =>
        [...index.bySku.values()]
          .map((c) => ({ ...c, score: Math.max(skuSimilarity(platformSku, c.sku), skuSimilarity(platformSku, c.name) * 0.6) }))
          .filter((c) => (c.score ?? 0) >= 0.3)
          .sort((a, b) => (b.score ?? 0) - (a.score ?? 0) || a.sku.localeCompare(b.sku))
          .slice(0, limit);
      export const matchSku = (channelId, platformSku, index) => {
        const listed = index.listingMap.get(listingKey(channelId, platformSku));
        if (listed) return { variantId: listed, source: 'listing_map', suggestions: [] };
        const exact = index.bySku.get(platformSku.trim());
        if (exact) return { variantId: exact.variantId, source: 'sku_exact', suggestions: [] };
        const normalised = index.byNormalisedSku.get(normaliseSku(platformSku)) ?? [];
        const only = normalised[0];
        if (normalised.length === 1 && only) return { variantId: only.variantId, source: 'sku_normalised', suggestions: [] };
        // Zero or ambiguous normalised hits: never guess, hand the user a ranked list.
        return { source: 'unmatched', suggestions: normalised.length > 1 ? normalised.map((c) => ({ ...c, score: 1 })) : suggestCandidates(platformSku, index, 5) };
      };
      ```
