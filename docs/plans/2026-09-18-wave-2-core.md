## Assumptions carried over from the Wave 1 plan

1. **Scene 3 = 103,400 baht.** The lot numbers (60 @ 1,000.00 older, 50 @ 1,085.00 newer, sell 100) are an assumption; only the 103,400 figure is customer-facing. Replaces nothing if the demo script says otherwise - update `fifo.test.ts` and re-run. CONFIRMED by the user on 2026-09-18: the numbers match the demo script, so the scene-3 test stands as written.
2. **Price tier semantics.** Three seeded tiers (`retail` ปลีก = default, `wholesale` ส่ง, `dealer` ตัวแทน). Resolution order: the customer's tier price, else the default tier price, else the variant's `sellingPrice`; the API reports which one it used (`priceSource`) so the bill screen can show it. A tier with no price for a variant is normal, not an error - a shop with 400 SKUs never fills every cell.
3. **Who sees tier prices.** `price_tier:read` goes to owner, manager and sales (sales bills with it); `stock_staff` gets neither cost nor tier data. Already encoded in `packages/core/src/rbac.ts` by commit `afd0844`.
4. **Marketplace shortfall.** A marketplace sale larger than open lots records only the units that had a lot (`onShortage: 'shortfall'`) and reports `shortfallQty`; the invariant `SUM(qty_delta) = SUM(remaining_qty)` stays intact (`packages/db/src/guards.integration.test.ts`). Surfacing that to the user is the next wave's apply step, not this plan.
5. **Lazada unit price.** The `unitPrice` column is the unit price and `sellerDiscountTotal` the line discount; `paidPrice` is NOT the unit price. The skipped test in `packages/adapters/src/lazada/adapter.test.ts` expects `25_900` / `2_000` and overrides any HANDOFF note saying otherwise.

## Global Constraints

Inherited unchanged from `AGENTS.md` and the Wave 1 plan; every task implicitly includes these.

- `packages/core` must not import Next.js, Hono, Drizzle, React, or the Cloudflare runtime; core is tested with plain `bun test`.
- Adapters only convert data: no database, no HTTP, no stock decisions; an adapter never throws on a bad row, it pushes a `ParseIssue` and continues.
- Money is always an integer in satang via the `Satang` type; never floats; convert only when displaying.
- Cost hiding is enforced at the API; when adding a field that contains cost, add its key to `COST_KEYS` in `packages/core/src/rbac.ts` in the SAME commit; from Track E on, tier fields follow the same rule with `PRICE_TIER_KEYS`.
- FIFO runs in one transaction with `SELECT ... FOR UPDATE` on lots; re-importing a file must not deduct stock twice (unique `(channelId, externalOrderId)`); returns restore the original lot slices.
- Every business table carries `org_id` and every repository query filters by it; enums are edited in core first, then mirrored in `packages/db/src/schema/enums.ts`, then `bun run db:generate`.
- TypeScript strict with `noUncheckedIndexedAccess` and `verbatimModuleSyntax`: always `import type`, no `any`, no `!`.
- Files `kebab-case.ts`; types `PascalCase`; enum-set constants `SCREAMING_SNAKE_CASE` next to their type; DB tables plural `snake_case`.
- Throw only `StockHubError` with a stable `code`; add new codes to `ERROR_STATUS` in `apps/api/src/middleware/error.ts`.
- Comments in English explaining why; on-screen text in Thai; Markdown one sentence per line; never the em dash character.
- Schema change means `bun run db:generate` and committing the generated SQL plus `meta/` files; never hand-edit SQL.
- New endpoint: zod schema in `apps/api/src/schemas/`, handler returns only through `ok()` / `paginated()`, guarded with `requirePermission()`, matching types in `apps/web/src/lib/api-*.ts`, contract table in `apps/api/README.md`.
- Contract marker rule: every field in `apps/api/src/types/contract*.ts` whose name is in `COST_KEYS` carries `/** cost field */` on the line above; every field whose name is in `PRICE_TIER_KEYS` carries `/** tier field */`; the Track E audit test enforces the first direction, Track P adds the reverse.
- Web pages fetch only through `apps/web/src/lib/` modules, render loading, empty and error states, wrap cost figures in `<CostValue>`, and put `role` in every `useApi` dependency list.
- Never log buyer data; never commit real customer export files or real secrets.
- Commit subjects at most about 50 characters, imperative, one commit does one thing, never add an AI agent as co-author.

      ```ts
      const bigrams = (s: string): Set<string> => { const n = normaliseSku(s); const out = new Set<string>(); for (let i = 0; i < n.length - 1; i++) out.add(n.slice(i, i + 2)); return out; };
      export const skuSimilarity = (a: string, b: string): number => {
        const na = normaliseSku(a), nb = normaliseSku(b);
        if (na === nb) return 1;
        if (na.length >= 4 && nb.length >= 4 && (na.includes(nb) || nb.includes(na))) return 0.8;
        const ba = bigrams(na), bb = bigrams(nb);
        if (ba.size === 0 || bb.size === 0) return 0;
        let shared = 0; for (const g of ba) if (bb.has(g)) shared++;
        return (2 * shared) / (ba.size + bb.size);   // Dice coefficient
      };
      export const suggestCandidates = (platformSku, index, limit) =>
        [...index.bySku.values()]
          .map((c) => ({ ...c, score: Math.max(skuSimilarity(platformSku, c.sku), skuSimilarity(platformSku, c.name) * 0.6) }))
          .filter((c) => (c.score ?? 0) >= 0.3)
          .sort((a, b) => (b.score ?? 0) - (a.score ?? 0) || a.sku.localeCompare(b.sku))
          .slice(0, limit);
      export const matchSku = (channelId, platformSku, index) => {
        const listed = index.listingMap.get(listingKey(channelId, platformSku));
        if (listed) return { variantId: listed, source: 'listing_map', suggestions: [] };
        const exact = index.bySku.get(platformSku.trim());
        if (exact) return { variantId: exact.variantId, source: 'sku_exact', suggestions: [] };
        const normalised = index.byNormalisedSku.get(normaliseSku(platformSku)) ?? [];
        const only = normalised[0];
        if (normalised.length === 1 && only) return { variantId: only.variantId, source: 'sku_normalised', suggestions: [] };
        // Zero or ambiguous normalised hits: never guess, hand the user a ranked list.
        return { source: 'unmatched', suggestions: normalised.length > 1 ? normalised.map((c) => ({ ...c, score: 1 })) : suggestCandidates(platformSku, index, 5) };
      };
      ```

      ```ts
      export const redactMiddleware = createMiddleware<AppEnv>(async (c, next) => {
        await next();
        const res = c.res;
        if (!res.headers.get('content-type')?.includes('application/json')) return;
        const auth = c.get('auth');
        if (!auth || res.status >= 400) return;   // error envelopes carry no business fields

        c.res = new Response(JSON.stringify(redacted), { status: res.status, headers });
      });
      ```
